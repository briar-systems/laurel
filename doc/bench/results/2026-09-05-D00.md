## Footprint

Peak resident set is `VmHWM` from `/proc/<pid>/status`, the highest the
kernel ever saw. CPU time is user plus system over the whole matrix, so
it covers all three routes at both connection counts.

| server | peak RSS | CPU time over the matrix |
|---|---:|---:|
| Laurel + hedge (single threaded) | 35.9 MiB | 57.47 s |
| Go net/http (GOMAXPROCS=1) | 18.1 MiB | 53.12 s |
| axum (tokio current_thread) | 10.6 MiB | 46.04 s |
| Go net/http (all cores) | 34.4 MiB | 445.03 s |
| axum (tokio multi_thread) | 17.0 MiB | 276.13 s |

## Cell health

Every request in every cell was answered with a 2xx status.

Transport errors are counted separately. oha ends a run by dropping
whatever is still in flight, so a count near the connection count is an
artifact of stopping rather than a server fault. Cells well above that
are listed here.

No cell exceeded one and a half transport errors per connection.
